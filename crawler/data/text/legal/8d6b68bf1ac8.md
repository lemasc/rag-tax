4 เมษายน 2560

ประกาศอธิบดีกรมสรรพากร
เกี่ยวกับภาษีเงินได้ (ฉบับที่ 292)
เรื่อง กำหนดการยื่นแบบแสดงรายการภาษี การชำระภาษี
และสถานที่ยื่นแบบแสดงรายการภาษี
อาศัยอำนาจตามความในมาตรา 11 มาตรา 59 มาตรา 69 ทวิ และมาตรา 3 เตรส
แห่งประมวลรัษฎากรอธิบดีกรมสรรพากรกำหนดการยื่นแบบแสดงรายการภาษีการชำระภาษี
และสถานที่ยื่นแบบแสดงรายการภาษีสำหรับการยื่นแบบแสดงรายการภาษีเงินได้หักณที่จ่าย
ผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host ไว้ ดังต่อไปนี้
ข้อ 1 ในประกาศนี้
“ระบบนำส่งภาษีเงินได้หักณที่จ่ายแบบ Host to Host” หมายความว่า
ระบบยื่นรายการข้อมูลภาษีเงินได้หัก ณ ที่จ่ายจากเครื่องคอมพิวเตอร์แม่ข่ายของผู้มีหน้าที่นำส่งภาษีเงินได้
หรือผู้ให้บริการแล้วแต่กรณีมายังเครื่องคอมพิวเตอร์แม่ข่ายของกรมสรรพากรผ่านเครือข่าย
อินเทอร์เน็ตในลักษณะเชื่อมต่อรับส่งข้อมูลระหว่างเครื่องคอมพิวเตอร์ตามที่กรมสรรพากรกำหนด
“ผู้ให้บริการ” หมายความว่าผู้ประกอบธุรกิจให้บริการการชำระเงินทาง
อิเล็กทรอนิกส์ตามพระราชกฤษฎีกาว่าด้วยการควบคุมดูแลธุรกิจบริการการชำระเงินทางอิเล็กทรอนิกส์
พ.ศ. 2551 ซึ่งเป็นผู้ให้บริการยื่นรายการข้อมูลภาษีเงินได้หัก ณ ที่จ่าย ผ่านระบบนำส่งภาษีเงินได้
หักณที่จ่ายแบบ Host to Host แทนผู้มีหน้าที่นำส่งภาษีเงินได้
ข้อ 2 กำหนดให้การยื่นรายการข้อมูลตามแบบ ภ.ง.ด.1 ภ.ง.ด.2 ภ.ง.ด.3 และ ภ.ง.ด.53
ผ่านระบบนำส่งภาษีเงินได้หักณที่จ่ายแบบ Host to Host เป็นการยื่นแบบแสดงรายการภาษี
ตามมาตรา 3 เตรส มาตรา 59 และมาตรา 69 ทวิ แห่งประมวลรัษฎากร
การยื่นแบบแสดงรายการภาษีตามวรรคหนึ่งให้ใช้สำหรับการยื่นแบบแสดง
รายการภาษีภายในกำหนดเวลาตามที่กำหนดในข้อ 5
ข้อ 3 ผู้มีหน้าที่นำส่งภาษีเงินได้ที่มีความประสงค์จะยื่นแบบแสดงรายการภาษีตามข้อ 2
ด้วยตนเอง จะต้องยื่นคำขอยื่นแบบแสดงรายการภาษีผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ
Host to Host (ภ.อ.01.1) พร้อมข้อตกลงในการยื่นแบบแสดงรายการและนำส่งภาษีผ่านระบบนำส่ง
ภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host ที่แนบท้ายประกาศนี้ต่ออธิบดีกรมสรรพากร ณ สำนัก
บริหารการเสียภาษีทางอิเล็กทรอนิกส์ กรมสรรพากร และเมื่อได้รับอนุมัติแล้ว ให้มีสิทธิยื่นรายการ
ข้อมูลตามแบบ ภ.ง.ด.1 ภ.ง.ด.2 ภ.ง.ด.3 และ ภ.ง.ด.53 ผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ
Host to Host โดยให้ถือเป็นสถานที่ยื่นแบบแสดงรายการภาษีได้อีกแห่งหนึ่ง

4 เมษายน 2560

ข้อ 4 ผู้ให้ บริ การที่ มีความประสงค์จ ะให้บ ริการยื่ นแบบแสดงรายการภาษีต ามข้อ 2
แทนผู้มีหน้าที่นำส่งภาษีเงินได้ จะต้องได้รับการแต่งตั้งให้เป็นตัวแทนหรือตัวแทนช่วงเพื่อยื่นแบบแสดง
รายการและนำส่งภาษีในนามผู้มีหน้าที่นำส่งภาษีเงินได้ โดยทำสัญญาการตั้งตัวแทนหรือสัญญาการตั้ง
ตัวแทนช่วงและมอบอำนาจให้กระทำการแทนเป็นลายลักษณ์อักษร และทำบันทึกข้อตกลงให้บริการยื่น
แบบแสดงรายการและนำส่งภาษีผ่านระบบนำส่งภาษีเงินได้หักณที่จ่ายแบบ Host to Host
กับกรมสรรพากรโดยมีข้อความอย่างน้อยตามที่แนบท้ายประกาศนี้
ผู้ให้บริการที่ได้ดำเนินการตามวรรคหนึ่งแล้ว ให้มีสิทธิยื่นรายการข้อมูลตามแบบ ภ.ง.ด.1
ภ.ง.ด.2 ภ.ง.ด.3 และ ภ.ง.ด.53 ผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host
แทนผู้มีหน้าที่นำส่งภาษีเงินได้ โดยให้ถือเป็นสถานที่ยื่นแบบแสดงรายการภาษีได้อีกแห่งหนึ่ง
ข้อ 5 การยื่นแบบแสดงรายการภาษีผ่านระบบนำส่งภาษีเงินได้หักณที่จ่ายแบบ
Host to Host ให้ยื่นได้ภายในเจ็ดวันนับแต่วันสิ้นเดือนของเดือนที่จ่ายเงินได้พึงประเมิน โดยไม่เว้น
วันหยุดราชการ กรณีวันสุดท้ายของการยื่นแบบแสดงรายการภาษีตรงกับวันหยุดราชการ ให้ยื่นได้ภายใน
วันทำการถัดไป และให้ยื่นแบบแสดงรายการภาษีภายในเวลา 22.00 นาฬิกา ของแต่ละวัน
ข้อ 6 ผู้มีหน้าที่นำส่งภาษีเงินได้หรือผู้ให้บริการต้องนำส่งเงินภาษี พร้อมกับการยื่นแบบ
แสดงรายการภาษีผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host การนำส่งเงินภาษี
ดังกล่าวจะต้องใช้วิธีการโอนเงินเข้าบัญชีเงินฝากธนาคารของกรมสรรพากร ผ่านระบบอิเล็กทรอนิกส์
(Electronic Payment)
ข้อ 7 ให้ผู้อำนวยการสำนักบริหารการคลังและรายได้ กรมสรรพากร เป็น “เจ้าหน้าที่
รับชำระเงินภาษีอากร” เพื่อรับชำระเงินภาษี
ข้อ 8 การนำส่งภาษีเงินได้ตามประกาศนี้ให้ถือว่าเป็นการสมบูรณ์ เมื่อได้มีการยื่นแบบ
แสดงรายการภาษีผ่านระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host โดยได้โอนเงินเข้า
บัญชีเ งินฝากธนาคารของกรมสรรพากร และได้รับใบเสร็จรั บเงิ นของกรมสรรพากรตามจํ านวนเงิ น

ข้อ 1. คำนิยาม
ให้คำหรือข้อความดังต่อไปนี้มีความหมายดังนี้
“ผู้มีหน้าที่นาํ ส่งภาษีเงินได้” หมายถึง ผู้จ่ายเงินได้ซ่ึงมีหน้าที่หักภาษีเงินได้ ณ ที่จ่ายและนำส่งภาษี
ให้กรมสรรพากรตามกฎหมาย และให้รวมถึงผู้มีเงินได้ซึ่งเป็นผู้ถูกหักภาษีเงินได้ ณ ที่จ่ายตามกฎหมายที่ได้รับ
แต่งตั้งจากผู้จ่ายเงินได้ให้หักภาษีเงินได้ ณ ที่จ่ายและนำส่งภาษีแทน โดยได้จัดทำสัญญาการตัง้ ตัวแทนและมอบอำนาจ
ให้กระทำการแทนเป็นลายลักษณ์อักษร
“ระบบนำส่งภาษีเงินได้หัก ณ ที่จ่ายแบบ Host to Host” หมายถึง ระบบยื่นรายการข้อมูลภาษีเงินได้
หัก ณ ที่จ่ายจากเครื่องคอมพิวเตอร์แม่ข่ายของผู้ให้บริการมายังเครื่องคอมพิวเตอร์แม่ข่ายของกรมสรรพากรผ่าน
เครือข่ายอินเทอร์เน็ตในลักษณะเชื่อมต่อรับส่งข้อมูลระหว่างเครื่องคอมพิวเตอร์ตามที่กรมสรรพากรกำหนด

-22.2 ผู้ให้บริการตกลงให้บริการเป็นตัวแทนของผู้มีหน้าที่นำส่งภาษีเงินได้ในการยื่นแบบแสดง

บันทึกข้อตกลงฉบับนี้มีผลใช้บังคับนับแต่วันที่ทงั้ สองฝ่ายได้ลงนามในบันทึกข้อตกลงฉบับนี้เป็นต้นไป
เว้นแต่กรณีที่มีการสิ้นสุดลงตามที่ระบุไว้ในข้อ 9
ข้อ 6. การรักษาข้อมูลความลับ
บรรดาเอกสารหรือข้อมูลใดๆ ที่ได้รับทราบจากการปฏิบัติตามบันทึกข้อตกลงฉบับนี้ ไม่ว่าจะอยู่
ในรูปแบบใดให้ถือว่าเป็นข้อมูลความลับร่วมกันทั้งสองฝ่าย ซึ่งทั้งสองฝ่ายจะต้องนำไปใช้ประโยชน์เพื่อให้บรรลุ
วัตถุประสงค์ตามบันทึกข้อตกลงฉบับนี้เท่านั้น โดยจะไม่นำไปใช้หรือแสวงหาประโยชน์เพื่อตนเองหรือบุคคลใดทั้งสิ้น
นอกจากนี้ทั้งสองฝ่ายจะไม่นำข้อมูลความลับดังกล่าวไปเปิดเผยต่อบุคคลใดเป็นอันขาด รวมทั้งจะดำเนินการ
ให้พนักงานหรือลูกจ้างหรือตัวแทนของตนหรือบุคคลอื่นใดที่รับรู้หรือรับทราบข้อมูลความลับดังกล่าว
อันเนื่องมาจากการปฏิบัติตามบันทึกข้อตกลงฉบับนี้ปฏิบัติตามเงื่อนไขดังกล่าวอย่างเคร่งครัดด้วย โดยเป็นการรักษา
ข้อมูลความลับตลอดไป ทั้งนี้ แม้ว่าบันทึกข้อตกลงฉบับนี้สิ้นสุดลงไม่ว่าด้วยเหตุใดๆ ก็ตาม เว้นแต่การเปิดเผย
ตามกฎหมาย หรือคำสั่งของศาล หรือได้รับความยินยอมเป็นหนังสือจากคู่สัญญาอีกฝ่ายหนึ่ง
ข้อ 7. การแก้ไขเปลี่ยนแปลงบันทึกข้อตกลง
หากฝ่ายใดฝ่ายหนึ่งมีความประสงค์จะแก้ไขเพิ่มเติม หรือเปลี่ยนแปลงข้อกำหนดและเงื่อนไขข้อหนึ่ง
ข้อใดไม่ว่าทั้งหมดหรือบางส่วนของบันทึกข้อตกลงฉบับนี้ จะต้องแจ้งให้อีกฝ่ายหนึ่งได้ทราบเป็นลายลักษณ์อักษร
ล่วงหน้าเป็นเวลาไม่น้อยกว่าหกสิบวัน และจะต้องได้รับความยินยอมเป็นลายลักษณ์อักษรจากอีกฝ่ายหนึ่ง โดยทั้งสองฝ่าย
ตกลงจะเจรจาทำความตกลงร่วมกันเป็นลายลักษณ์อักษรต่อไป และให้ถือบันทึกข้อตกลงดังกล่าวเป็นส่วนหนึ่ง
ของบันทึกข้อตกลงฉบับนี้ด้วย
ข้อ 8. การแก้ไขปัญหาข้อขัดข้อง
หากมีปัญหาข้อขัดข้องใดๆ ในการปฏิบัติงานตามบันทึกข้อตกลงฉบับนี้ ทั้งสองฝ่ายตกลงที่จะร่วมกัน
พิจารณากำหนดแนวทางปฏิบัติและแก้ไขปัญหาที่เกิดขึ้นต่อไป
ข้อ 9. การบอกเลิกและการสิ้นสุดของบันทึกข้อตกลง
9.1 ในกรณีที่เกิดเหตุการณ์ใดเหตุการณ์หนึ่งซึ่งส่งผลให้ฝ่ายใดฝ่ายหนึ่งไม่สามารถปฏิบัติ
ตามบันทึกข้อตกลงฉบับนี้ต่อไปได้ ให้อีกฝ่ายหนึ่งมีสิทธิบอกเลิกบันทึกข้อตกลงฉบับนี้โดยต้องส่งคำบอกกล่าวเป็น
ลายลักษณ์อักษรให้อีกฝ่ายหนึ่งทราบล่วงหน้าเป็นเวลาไม่น้อยกว่าหกสิบวัน และเมื่อครบกำหนดเวลาตามที่ได้บอก
กล่าวแล้วถือว่าบันทึกข้อตกลงฉบับนี้เป็นอันสิ้นสุดลง

-49.2 เมื่อบันทึกข้อตกลงฉบับนี้เป็นอันสิ้นสุดลงตามข้อ 9.1 หรือสิ้นสุดลงไม่ว่าด้วยเหตุใดๆ ก็ตาม
หากฝ่ายใดฝ่ายหนึ่งยังมิได้ปฏิบัติงานตามที่กำหนดไว้ในบันทึกข้อตกลงฉบับนี้ให้ถูกต้องครบถ้วน หรือยังอยู่ระหว่าง
การดำเนินการ ฝ่ายนั้นตกลงยอมรับว่าตนยังคงมีหน้าที่ที่จะต้องดำเนินการ หรือปฏิบัติงานที่ค้างอยู่นั้นให้เสร็จสิ้น
เพื่อไม่ให้เกิดผลเสียหายแก่อีกฝ่ายหนึ่ง ยกเว้นจะมีกฎหมาย กฎเกณฑ์ และประกาศที่เกี่ยวข้องกำหนดเป็นอย่างอื่น
หรือทั้งสองฝ่ายจะได้ตกลงกันเป็นลายลักษณ์อักษรร่วมกันกำหนดเป็นอย่างอื่น
บันทึกข้อตกลงฉบับนี้ทำขึ้นเป็นสองฉบับ ซึ่งมีข้อความถูกต้องตรงกัน ทั้งสองฝ่ายได้อ่านและเข้าใจ
ข้อความในบันทึกข้อตกลงฉบับนี้โดยละเอียดตลอดแล้ว เห็นว่าถูกต้องตรงความประสงค์ของทั้งสองฝ่ายทุกประการ
