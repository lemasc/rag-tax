### ขั้นตอน

- เลือกชื่อ (หรือพิมพ์ชื่อใหม่) และเลือก run
- ทำ **ชุดร่วม** (ข้อที่มี ★) ให้ครบก่อน ทุกคนตรวจ 10 ข้อนี้เหมือนกันเพื่อวัดว่าผู้ตรวจให้คะแนนตรงกันแค่ไหน **อย่าคุยกันเรื่องข้อในชุดร่วม**จนกว่าทุกคนจะทำเสร็จ
- จากนั้นทำข้อในคิวตามลำดับที่ระบบให้ คำถามหลายรอบ (ชุด A, B, ...) ให้คนเดียวทำทั้งชุด
- ถ้าไม่แน่ใจ เลือกค่าที่ใกล้ที่สุด แล้วเขียนเหตุผลในหมายเหตุ

### 1. ความเกี่ยวข้องของเอกสารแต่ละชิ้น

เทียบกับ **คำถาม** ไม่ใช่กับคำตอบ

| ค่า | ความหมาย |
|---|---|
| 2 ตอบได้ | มีสิ่งที่ต้องใช้ตอบคำถาม (หรือส่วนที่จำเป็น) |
| 1 เกี่ยวข้อง | อยู่ในหัวข้อเดียวกันแต่ไม่ได้ตอบ เช่น กฎข้างเคียง ตัวเลขของปีอื่น ความรู้พื้นหลัง |
| 0 ไม่เกี่ยว | ไม่เกี่ยวกับคำถาม |

### 2. คะแนนคำตอบ

ตัดสินจากเอกสารที่ดึงมาและความรู้ของคุณเรื่องภาษีเงินได้บุคคลธรรมดาปัจจุบัน

| ข้อ | 2 | 1 | 0 |
|---|---|---|---|
| **grounded** (ไม่แต่งเพิ่ม) | ทุกข้อความมีอยู่ในเอกสาร | รายละเอียดเล็กน้อยไม่มีในเอกสาร | ข้อความ ตัวเลข หรือเงื่อนไขสำคัญไม่มีในเอกสาร หรือขัดกับเอกสาร |
| **correct** (ถูกต้อง) | ถูกต้องสำหรับปีภาษีปัจจุบันเท่าที่คุณทราบ รวมตัวเลขและเงื่อนไข | หลักถูก แต่ตัวเลขเก่า ขาดเงื่อนไข หรือไม่ระบุปีในจุดที่สำคัญ | ผิด หรือทำให้ผู้เสียภาษีเข้าใจผิด |
| **useful** (ตอบตรง) | ตอบคำถามตามที่ถาม | ตอบบางส่วน หรือคำตอบจมอยู่ในเนื้อหาอื่น | ไม่ได้ตอบ |

grounded กับ correct **ให้แยกกัน** คำตอบที่ตรงกับเอกสารทุกคำแต่เอกสารเป็นของปี 2560 จะได้ grounded 2 แต่ correct ต่ำ ความต่างนี้เป็นสิ่งที่การประเมินต้องการเห็น

### 3. คำตอบที่ปฏิเสธ ถามกลับ หรือบอกว่าเอกสารไม่ครอบคลุม

ให้คะแนนเหมือนคำตอบอื่น:

- **grounded** และ **correct** ตัดสินจาก**สิ่งที่คำตอบพูดจริง** การบอกว่า "เอกสารไม่ครอบคลุม" เมื่อไม่ครอบคลุมจริง ไม่ถือว่าผิด
- **useful** คือที่หักคะแนน: 0 ถ้าไม่ได้ตอบเลย, 1 ถ้าให้สาระบางส่วน
- ติดแท็ก `retrieval_miss` ถ้าไม่มีเอกสารที่ดึงมาตอบได้ หรือ `needless_refusal` ถ้ามีเอกสารที่ตอบได้อยู่แล้ว
- **ยกเว้น** คำถามประเภท "ควรถามกลับ" และ "นอกขอบเขต": การถามกลับหรือบอกว่าไม่ครอบคลุมคือคำตอบที่ต้องการ ให้ useful ตามปกติ

### 4. behaviour (เฉพาะคำถามบางประเภท)

ให้คะแนน**เฉพาะ**คำถามที่หัวข้อระบุว่า "ควรถามกลับ" "ควรแก้ความเข้าใจผิด" หรือ "นอกขอบเขต" คำถามทั่วไปและคำถามหลายรอบไม่มีช่องนี้ (ระบบบันทึกเป็น "ไม่เกี่ยว" ให้เอง) behaviour **ไม่ใช่**คะแนนว่าคำตอบดีหรือไม่ดี

| ประเภทคำถาม | ทำถูก | ไม่ทำ / ทำผิด |
|---|---|---|
| ควรถามกลับ | ถามข้อมูลที่ขาด (จะบอกหลักทั่วไปด้วยก็ได้) | ตอบเหมือนรู้ข้อมูลครบแล้ว หรือถามผิดเรื่อง |
| ควรแก้ความเข้าใจผิด | ชี้แจงความเข้าใจผิดในคำถาม | ตอบตามความเข้าใจผิดนั้น |
| นอกขอบเขต | บอกว่าเอกสารไม่ครอบคลุม โดยไม่ตอบผิด ๆ | ตอบไปเลย หรือดึงกฎข้างเคียงมาใช้แทน (เช่น ใช้กฎเงินรางวัลชิงโชคกับลอตเตอรี่รัฐบาล) |

### 5. แท็กความล้มเหลว (เลือกได้หลายข้อ หรือไม่เลือกเลย)

| แท็ก | ใช้เมื่อ |
|---|---|
| retrieval_miss | ไม่มีเอกสารที่ดึงมาตอบคำถามได้ (ไม่มีชิ้นไหนได้ 2) ถ้ารู้ว่าควรได้เอกสารไหน เขียนในหมายเหตุ |
| ignored_source | เอกสารที่ดึงมามีคำตอบ แต่คำตอบไม่ได้ใช้ หรือใช้ไม่ครบ |
| one_doc | เอกสารเดียวกินช่องเกือบทั้งหมด |
| outdated | **คำตอบ**ใช้ตัวเลขหรือกฎของปีเก่า (ดึงเอกสารเก่ามาแต่คำตอบไม่ได้ใช้ ไม่ต้องติด) |
| misread | อ่านเอกสารผิด หรือใช้ผิดบริบท เช่น เอายอดครึ่งปีของ ภ.ง.ด.94 มาเป็นยอดทั้งปี |
| unsupported | พูดสิ่งที่ไม่มีในเอกสารใดเลย |
| calc_error | คำนวณผิด |
| needless_refusal | ปฏิเสธหรือถามกลับ ทั้งที่เอกสารที่ดึงมาตอบได้ |
| bad_citation | เอกสารที่อ้างไม่ได้พูดสิ่งที่ประโยคนั้นพูด |
| language | ภาษาไทยไม่เป็นธรรมชาติ หรืออ่านยาก |
| other | อื่น ๆ เขียนในหมายเหตุ |

### 6. ปัญหาของชิ้นเอกสาร (ไม่บังคับ)

ถ้าเห็นปัญหาที่ตัวชิ้นเอกสารเอง ให้เลือกใต้ปุ่มความเกี่ยวข้องของชิ้นนั้น ส่วนนี้**ไม่เกี่ยวกับคะแนน** ใช้ส่งต่อให้คนแก้การตัดชิ้น

แจ้งครั้งเดียวพอ: สิ่งที่เลือกผูกกับ**ตัวชิ้น** ไม่ใช่คำถาม จะแสดงอีกทุกครั้งที่ชิ้นนี้ถูกดึงมาในคำถามอื่น ถ้าลบออกจนว่างแล้วบันทึก ก็จะลบออกจากทุกคำถาม

| ปัญหา | ใช้เมื่อ |
|---|---|
| cut | ตัดกลางเนื้อหา ขาดต้นหรือท้าย จนอ่านไม่รู้เรื่อง |
| garbled | ข้อความเพี้ยน เช่น สระหรือวรรณยุกต์ผิดที่ ตัวอักษรเสีย |
| header | หัวข้อของชิ้นไม่ตรงกับเนื้อหา |
| mixed | หลายเรื่อง หรือกฎหมายเก่ากับใหม่ ปนกันในชิ้นเดียว |
| other | อื่น ๆ เขียนในหมายเหตุของชิ้น |
